# 08 · 공방(攻防) 설계 — 막고 → 흔들고 → 무너뜨린다 (에이전트 X, 2026-10-10)

감독 승인 과제: 자동 전투를 '보는 맛'이 있는 주고받기로. 양쪽에서 몰려드는 적이 한꺼번에 덤비지 않고(쿵후 영화의 원),
막힌 공격 → 높이를 바꾼 공격 → **GUARD BREAK!** → 콤보가 6~12초마다 눈에 보이게.
**전부 `SimConfig.nativeMoves` 뒤**(그 안에서 `nativeGuard` — 기본 켬, 밸런스 비교용으로만 끈다). 깃발이 꺼지면 코드 경로 · 난수 소비 · 데이터가 웹 그대로(락스텝 28판 · 분포 · 픽스처 통과).

| 대기 자리 | 쪽마다 가까운 순 36 · 55 · 74 · 93px …(19px 간격 — 인물 몸통 폭보다 넓게). 적이 많아 칸 끝까지 모자라면 간격을 줄이되 최소 17px, 그래도 넘치면 자리가 칸 끝 너머(화면 밖 근처 — 칸 벽 +26px 까지)로 이어진다. 그곳에서 기다리는 적끼리는 몸 밀기가 벽에 눌러 겹치게 하지 않는다(타워는 엘리베이터 벽 안). 자리보다 안쪽이면 가드를 올린 채 1.5배로 물러선다 · 셔플 ±3px |
| 대기 동작 | 가드를 올림(서서 / 성향 lowP 로 앉아 — 1.6~3.2초마다 다시 고름) · 서서 막기는 ±5px 셔플(0.8~1.6초) · 페인트(2.4~5초마다 30%, 치고 빠지기형 55% · 22px — 쉬던 주인공은 50% 로 움찔 가드) · 도발(손짓 · '덤벼' — 4.5~8.5초마다 35%, 셋 중 하나는 '덤벼!' 말풍선) |

**주인공 AI 가 가드를 읽는다** — 막히면 바로 다시 고른다(`nvc.repick`). `pickSkill` 가중: 상대 자세(또는 2.5초 안에 막은 높이)를 이기는 높이 ×4 ·
막히는 높이 ×0.65(방금 막힌 높이면 ×0.3, 무거운 H 는 ×1.8 — 게이지를 크게 깎으니) · 앉아 막기에 상단 ×0.1 · 서서 막기에 리버/코크스크루 ×4 · 잡기 ×4.
주먹 콤보는 앉아 막는 상대에게 어퍼(중단)로 건너뛴다. 맞는 기술이 없으면 계속 두들겨 게이지를 깬다. 콤보 경로 · 가방 기술 안에서만 고른다.
가드를 올린 대기 적보다 20px 안쪽으로 먼 무방비 적이 있으면 그쪽을 먼저 노린다(막기만 두들기지 않게).

**주인공 가드** — 앞에서 적이 공격을 예고(타격까지 ≤ 0.45초 · 닿는 거리)하면, 쉬는 중이거나 자기 기술의 회복 칸(타격이 끝난 뒤)일 때 60%(직접 조작 중 40%)로 가드:
상단 예고 + 쭈그리기 준비면 앉아 흘리기(쭈그리기 쿨 사용), 하단 예고는 35% 만 앉아 막기로 읽는다(서서 막기를 하단으로 뚫을 수 있게), 나머지는 서서 막기.
등 뒤 위협은 0.18초 이상 남았을 때만 돌아서 막는다. 받아치기 기술(팔꿈치 · 숄더 롤)이 준비돼 있으면 가드 대신 그쪽. 막은 직후 0.5초는 `counter` 조건이 선다(막고 → 받아치기).
**저스트 가드** — 가드 중(또는 막은 직후 0.25초) 그쪽을 누르면: 막 막은 적 또는 타격 직전(저스트 창 ×1.6) 적에게 `justCounter`(웹 그대로 — 크로스 치명 · 무릎 꿇림) +
'JUST GUARD!' · 흰 고리 · 게이지 가득. 가드가 아닐 때의 탭(저스트 · 카운터 · 대시)은 그대로.

## 4. 표현(실제 화면 크기에서 읽히게)

- 서서 막기: 두 주먹이 이마 · 턱 앞에 붙은 '닫힌' 실루엣(평소 자세는 앞팔을 내민다) · 무릎 살짝. 앉아 막기: 엉덩이 13px 내려가고 팔이 정강이 앞. 막는 순간: 뒤로 젖혀지며 팔을 조임.
  크래시: 팔이 위 · 앞으로 튕겨 열리고 상체가 뒤로 → 팔을 늘어뜨린 채 휘청. 끼어들기: 무릎을 높이 든 뒤 바닥을 구른다(먼지 · 바닥 충격).
- 막기 불꽃: 맞닿은 자리에서 때린 쪽으로 튀는 흰/하늘 선 7~9개 + 방패 호 + 무대 불꽃(광원). 글자 '막!'(쳐내기 '쳐냄!', 흘림 '휙')은 연속 막기 처음 · 1.2초에 한 번만 — 글자 홍수 없이.
- 가드 게이지: 머리 위(체력 막대 위) 작은 방패 + 14px 막대. ⅔ · ⅓ 아래로 금, ⅓ 아래 빨강 깜빡임, 막은 순간 흰색, 앉아 막기는 노란 방패. 가드 중 · 막은 지 1.5초 안 · 덜 찬 동안만.
- 눈으로 확인: `BB_DUMP=1 swift test --filter NativeGuardStripTests` → `tools/js/out/guard/` poses_1x(실제 1배 ×3 확대) · poses_2x · poses_zoom_a/b · block · crash · hero · cutin · crowd.
  반복해서 고친 점: 9999ms 한 칸짜리 가드 시퀀스는 보간(칸 길이 × 0.6)이 몇 초 걸려 가드가 안 보임 → 짧은 첫 칸 + 버티는 둘째 칸 / '막!' 글자가 체력 · 게이지 막대와 겹침 → 불꽃 옆 아래로 /
  크래시 별 터짐이 화면을 덮음 → 반지름 56 → 44 / 끼어들기 '!' 가 머리 위 잘림 → 70px 로 내리고 크게.
