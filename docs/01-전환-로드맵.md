# 01 · 전환 로드맵

원칙은 하나다: **단계마다 실기기에서 재고, 숫자로 다음을 정한다.** 측정 전에 큰 재작성을 시작하지 않는다.

```
0단계 준비(이 패키지) ─▶ 1단계 웹 코어 + 셸 · 실기기 측정 ─▶ [판정 게이트]
                                                              ├─ A 웹 코어 유지 → 1.5단계 정리 → 출시 준비(스킨 결제 · 리더보드)
                                                              ├─ B 웹 최적화 / 렌더러만 네이티브
                                                              └─ C 엔진 재작성(최후)
```

## 판정 게이트
기준 기기 = **지원하려는 가장 낮은 기기**(예: A13급 아이폰 11 / SE 2세대). 주 시나리오 = S3(지하철 전투 절정) · S4(타워 15~20층).

| 지표 | 통과 → A | 경계 → A + 최적화 | 실패 → 원인 분석 후 B/C |
|---|---|---|---|
| 평균 FPS (60초) | ≥ 58 | 50 ~ 58 | < 50 |
| 프레임 시간 p95 | ≤ 20ms | 20 ~ 28ms | > 28ms |
| 긴 프레임(>50ms) | 분당 ≤ 1 | 분당 2 ~ 5 | 분당 > 5 |
| 15분 연속 뒤 발열 | nominal · fair | serious 잠깐 | serious 지속 · critical |
| 30분 배터리 소모 | ≤ 8% | 8 ~ 12% | > 12% |
| WebContent 종료 · gl.lost | 30분에 0회 | — | 1회 이상 |
| 터치 반응(저스트 탭 · 가방 끌기) | 웹과 같거나 낫다 | 약간 늦다 | 판정이 틀어진다 |

실패일 때는 **원인부터 가른다**(Safari 웹 인스펙터 Timelines · Instruments):
- JS 실행이 프레임을 먹는다 → 게임 로직 핫스팟 최적화(웹에서 해결 가능)
- GPU/합성이 먹는다 → 내부 해상도 · 광원 수 · 후처리 단계를 낮추는 **품질 등급**(B0)
- 둘 다 한계 → B(렌더러 Metal 이식) 또는 C 검토

## 2단계 갈림길
**A. 웹 코어 유지 + 네이티브 강화 (기본 기대 경로)**
1. 1.5단계 정리(아래)
2. StoreKit 2 — 주인공 양복 스킨 3종 인앱 결제(브리지 `iap.*`, 게임 쪽 `OPT.skin` 해금과 연결)
3. Game Center — 타워 최고 층 · 오늘의 타워 리더보드(브리지 `gc.*`)
4. 공유 — 결과 신문 1면 이미지(`share.image`)
5. iCloud 저장 동기화(NSUbiquitousKeyValueStore 또는 CloudKit — 저장 크기 보고 결정)
6. 광고(보상형) — 넣는다면 마지막. 개인정보 · 추적 동의(ATT) 문구 동반

**B. 웹 최적화 / 렌더러만 네이티브** — B0 품질 등급을 먼저. 그래도 모자라면 WebGL 파이프라인(G-버퍼 · 광원 · 후처리)만 Metal로 옮기고 로직은 JS 유지. 비용 큼.

**C. 엔진 재작성** — Swift + Metal 또는 다른 엔진. 1만 줄 로직 이식 · 절차 아트 재현 비용 때문에 최후 수단.

## 1.5단계 · 출시 전 정리 (A 선택 시)
- `tools/split_web.py split`로 조각 분리 → 이후 `web/src/`가 정본, `join`으로 단일 HTML 생성(클라우드 세션 작업 방식과 합의 필요)
- 게임에 정식 호스트 API `window.BAGBOSS_HOST`(pause · resume · save · state · skin 해금) — `__dotlab` 의존 끊기
- 앱 빌드에서 개발 도구 제외(엔진 실험실 · 노드 에디터 · 자세 편집기 · 무도장 · 개발자 패널 ≈ 170KB) — `dev` 그룹 조각 빼고 합치기
- 앱 화면 정리: PC 목업 · 실험실 탭 · 키보드 안내 숨김, 세로 한 화면 배치 확인
- App Store 준비: 아이콘 · 스크린샷 · 개인정보 처리방침 · 연령 등급(폭력 묘사: 만화풍 격투)
