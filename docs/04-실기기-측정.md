# 04 · 실기기 측정

목표: **판정 게이트(docs/01)의 표를 채울 숫자**를 얻는다. 감으로 "괜찮다"가 아니라 CSV로 말한다.

## 1. 기기
가능하면 세 대. 한 대뿐이면 지원하려는 가장 낮은 기기를 우선.
| 역할 | 예 | 보는 것 |
|---|---|---|
| 기준(최저 지원) | A13급 — 아이폰 11 · SE 2세대 | 통과/실패 판정 |
| 보통 | 최근 일반 모델 | 다수 사용자 체감 |
| 프로모션(120Hz) | 프로 모델 | 웹 rAF가 60에 묶이는지 · 발열 |

## 2. 도구
- **성능 HUD**: 디버그 빌드는 처음부터 보임 · 릴리스는 세 손가락 두 번 탭. 탭 = 자세히, 끌기 = 옮기기, 길게 = CSV 공유
- **CSV**: `Documents/perf/session-*.csv` (파일 앱 › 나의 iPhone › BAG BOSS › perf). 1초 한 줄 + 사건 줄
  열: `t, fps, p50, p95, max, long, scene, px, thermal, battery, appMemMB, event, detail`
  사건: `launch · loaded · ready · resignActive · active · background · thermal · memoryWarning · glLost · webContentTerminated · jsError`
- **Safari 웹 인스펙터**(디버그 빌드, iOS 16.4+): 맥 Safari › 개발자 › [아이폰] › BAG BOSS → Timelines(JS · 렌더링 · 메모리)
  - `appMemMB`는 앱 프로세스만이다. **게임 메모리(JS 힙 · WebGL)는 인스펙터의 Memory 타임라인**으로 본다.
- **Instruments**: Energy Log(배터리 영향) · Thermal State · Game Performance(프레임 · GPU). 15분 이상 기록.

## 5. 기능 체크리스트
**화면 · 입력**
- [ ] 노치 · 다이내믹 아일랜드 아래로 게임 HUD가 가려지지 않는다(safe-area)
- [ ] 아래쪽 가방 끌기가 홈 제스처에 먹히지 않는다(첫 스와이프는 막히고 두 번째에 홈)
- [ ] 두 번 탭 · 핀치로 확대되지 않는다 · 길게 눌러도 복사/공유 메뉴가 안 뜬다
- [ ] 저스트 탭 타이밍이 데스크톱/사파리와 같은 느낌(늦게 판정되면 기록)
- [ ] 영어 전환(메뉴 › 설정) 후 다시 열려도 영어

**소리**
- [ ] 첫 터치에 소리가 켜진다 · 무음 스위치 켜면 소리 없음(.ambient) — 의도와 맞는지 결정
- [ ] 다른 앱 음악을 틀어 둔 채 켜면 음악이 계속된다(mixWithOthers)
- [ ] 전화/알람 인터럽트 뒤 돌아오면 소리가 다시 난다

**햅틱**
- [ ] 넘어뜨림/치명타 · 주인공 피격 · KA-BOOM · 두목 등장 · 필살기 · 차 부수기가 각각 다른 무게로 느껴진다(docs/03 표)
- [ ] 주인공 피격(가장 잦음) 진동이 피곤하지 않다 — 피곤하면 세기를 낮추거나 끄는 옵션 분리
- [ ] 다단 히트에서 진동이 뭉개져 웅웅거리지 않는다 · 옵션에서 진동 끄면 안 울린다

**수명주기 · 저장**
- [ ] 싸우는 중 홈으로 → 돌아오면 메뉴가 열린 채 멈춰 있다
- [ ] 판 중간에 앱 강제 종료 → 다시 켜면 '이어 하기'가 그 칸에서 된다
- [ ] 설정 › Safari › 방문 기록 및 웹사이트 데이터 지우기 → 앱 기록 유지(WKWebView 저장소는 앱 단위라 영향 없어야 함)
- [ ] **복원 시험**: 디버그 메뉴 없이 하려면 앱 삭제 전 `save.json`을 파일 앱으로 확인 → (2단계 iCloud 전에는 재설치 시 기록이 사라지는 게 정상)
- [ ] 다른 무거운 앱 여러 개 띄운 뒤 돌아오기 → 화면이 검게 남지 않는다(glLost · 종료 시 자동 재시작 확인)

## 6. 해석 메모
- 프로 기기에서 FPS가 60 근처면 WebKit이 rAF를 60Hz로 묶은 것 — 정상. 120 목표는 2단계 이후 검토.
- p50은 좋은데 p95 · 긴 프레임이 나쁘면 **가비지 수집 · 셰이더 컴파일 · 아틀라스 재생성** 의심 → 인스펙터 Timelines에서 그 순간을 찾는다.
- 발열이 serious로 가면 FPS가 같이 떨어지는지 본다(스로틀링). 떨어지면 품질 등급(B0)이 1순위 대책.
- `px`(내부 캔버스 해상도)는 기기 픽셀 기준 정수배다. 3배 기기에서 1110×624 수준 — 이 크기가 GPU 부담의 대부분이면 2배 고정 옵션이 가장 싼 대책.
